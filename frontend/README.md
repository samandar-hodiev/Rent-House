# RentHouse — Frontend

React + Vite + Tailwind CSS + React Router. JavaScript only.

## Scripts

```
npm run dev      # start dev server
npm run build    # production build
npm run lint     # oxlint
npm run preview  # preview production build
```

## Structure

```
src/
  assets/       static assets (images, icons)
  components/   reusable UI components (Header, Footer, Container, ...)
  layouts/      page layout shells (RootLayout)
  pages/        route-level page components
  routes/       route path constants
  App.jsx       router setup
  main.jsx      app entry point
```

See the root [CLAUDE.md](../CLAUDE.md) for full project conventions.
